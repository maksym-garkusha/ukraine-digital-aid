# Безпека

ukraine-digital-aid це незалежний навчальний проєкт на відкритих даних IATI, не пов'язаний з державними органами чи донорами. Якщо ви знайшли вразливість, повідомте приватно, а не у відкритому issue.

## Як повідомити

На вкладці Security цього репозиторію натисніть «Report a vulnerability». Це приватне повідомлення GitHub, його бачить тільки власник репозиторію. Опишіть, що знайшли і як це відтворити. Запит і відповідь, якщо вони є, додавайте без чужих персональних даних.

Відповідь протягом 7 днів. Винагород за знахідки немає.

## Що в межах

- сторінка https://maksym-garkusha.github.io/ukraine-digital-aid/ і файли поруч із нею: `data.json`, `snapshot.json`, стрічки `changes.atom` і `changes.en.atom`, `report.md`;
- код і workflow GitHub Actions у цьому репозиторії, зокрема атестація походження файлів.

## Що поза межами

- d-portal і реєстр IATI: про них варто писати їхнім власникам;
- зміст записів, які опублікували донори: назви, суми, виконавці;
- GitHub і GitHub Pages як платформи;
- навантажувальні тести і соціальна інженерія.

## English

ukraine-digital-aid is an independent learning project on IATI open data, not affiliated with any government body or donor. To report a vulnerability, use "Report a vulnerability" on the Security tab of this repository (GitHub private vulnerability reporting) rather than a public issue.

In scope: the page on GitHub Pages and the files next to it (`data.json`, `snapshot.json`, the `changes.atom` and `changes.en.atom` feeds, `report.md`), and the code and workflows in this repository, including the provenance attestations. Out of scope: d-portal and the IATI registry, the content of records published by donors, GitHub as a platform, load testing and social engineering.

You will get a reply within 7 days. There is no bug bounty.
